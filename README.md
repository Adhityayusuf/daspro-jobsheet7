# Daspro Jobsheet 7 — Perulangan (While, Do-While, For)

Program latihan **struktur perulangan** pada Java: `while`,
`do-while`, dan `for`.

## Daftar Program

| Program | Deskripsi |
|---------|-----------|
| `siakadWhile13.java` | Perulangan `while` — studi kasus SIAKAD |
| `kafeDoWhile13.java` | Perulangan `do-while` — menu kafe berulang |
| `siakadFor13.java` | Perulangan `for` — studi kasus SIAKAD |
| `tugas1.java`, `tugas2.java` | Tugas jobsheet |

## Cara Menjalankan

```bash
javac siakadWhile13.java
java siakadWhile13
```
